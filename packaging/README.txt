Tradewind 浏览器绿色版使用说明
===============================

一、首次使用
1. 将 ZIP 完整解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 Tradewind.exe，等待默认浏览器打开 http://127.0.0.1:8101/。
3. 首次使用请在“设置”中填写自己的开发信模型和视觉模型 API Key。
4. 黑色启动窗口必须保持打开；关闭该窗口即完全退出 Tradewind。

二、日常使用
- 重复双击 Tradewind.exe 只会重新打开页面，不会重复启动后端。
- 浏览器没有自动打开时，可手动访问 http://127.0.0.1:8101/。
- 更新软件时先关闭旧版，再解压新版；默认模式下原有数据不会被覆盖。

三、数据保存位置
- 默认保存在 %LOCALAPPDATA%\Tradewind\data，适合大多数用户。
- 如需把数据和程序一起放在 U 盘或文件夹中，请在首次启动前将
  portable.flag.example 重命名为 portable.flag。
- 上述两种模式使用不同的数据目录。切换前请先备份，不会自动迁移。
- API Key、客户名单、爬虫照片及历史记录都只保存在本机，不包含在发布包中。

四、爬虫要求
- 电脑需要已安装 Microsoft Edge 或 Google Chrome，程序不会额外安装浏览器。
- Google Maps 在部分网络环境中可能需要可用代理。

五、常见问题
- 提示端口 8101 被占用：关闭旧的 Tradewind 窗口或占用该端口的其他程序。
- 页面显示“拒绝连接”：确认黑色启动窗口仍在运行，然后重新双击 Tradewind.exe。
- 显示“后端启动超时”：先保持窗口打开并手动访问 http://127.0.0.1:8101/；
  若仍无法访问，请确认 ZIP 已完整解压且 _internal 文件夹未被杀毒软件隔离。
- Windows 出现安全警告：当前内部版本未做代码签名，只应运行来自可信来源的文件。
- 换电脑后没有原数据或 Key：这是正常现象，需要在新电脑重新配置或迁移数据目录。
- 视觉识别失败：记录界面显示的 provider、model、HTTP 状态或超时阶段再排查。
- 需要售后排查：到“设置 → 本地诊断与售后”主动导出诊断包后再发送。
  软件不会后台上传使用情况；诊断包也不包含 Key、客户、邮件、照片或原始日志。
